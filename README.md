# 🤖 — CodeAlpha_Basic Console Chatbot 

A lightweight, rule-based interactive chatbot developed in Python for the **CodeAlpha Python Programming Internship (TASK - 3)**.

---

## 💡 Overview

This project is a terminal-based chatbot that simulates natural conversational flows using keyword matching, pattern validation, and intent recognition. It processes user input dynamically and responds with contextual messages without requiring any heavy third-party NLP libraries.

---

## ✨ Key Features

- 💬 **Dynamic Conversational Responses:** Uses multiple randomized reply pools for greetings, casual checks, and goodbyes so conversations don't feel repetitive.
- 🧮 **Quick Math Evaluation:** Built-in calculation utility capable of evaluating basic arithmetic expressions safely (e.g., `calc 15 * 4`).
- 🕒 **Live System Utilities:** Fetches real-time system date, day, and time dynamically on demand.
- 🛡️ **Robust Input Handling:** Strips unnecessary whitespace, handles case-insensitivity seamlessly, and ignores accidental blank enters.
- ⚡ **Zero External Dependencies:** Built purely with Python standard modules (`datetime`, `random`, `re`).

---

## 🛠️ Tech Stack & Concepts Used

| Component | Details |
|---|---|
| **Language** | Python 3.8+ |
| **Modules Used** | `datetime`, `random`, `re` |
| **Core Concepts** | String methods, Loops (`while`), Regex pattern matching, Dictionaries |
